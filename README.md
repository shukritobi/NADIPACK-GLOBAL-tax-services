# Nadipack Global Tax Services Website

A responsive, Malay-first landing website for Nadipack Global's bookkeeping and tax-support services.

## Included

- Conversion-focused one-page website
- Mobile navigation
- Service and package sections
- FAQ accordion
- WhatsApp lead form with pre-filled message
- SEO metadata and structured data
- Responsive layout and accessibility support
- SVG favicon and social sharing card

## Local preview

Open `index.html` directly, or run a local static server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

This is a static website and can be deployed on GitHub Pages, Cloudflare Pages, Netlify, or any regular web hosting.

### GitHub Pages

1. Open the repository **Settings**.
2. Go to **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`.
5. Save.

The expected URL is:

`https://shukritobi.github.io/NADIPACK-GLOBAL-tax-services/`
